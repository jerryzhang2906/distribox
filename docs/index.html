DistriBox

把多台设备的算力聚合成一个虚拟 GPU

🖥 Windows 📱 Android Go + C MIT
⬇ Download v0.3.0 ⭐ GitHub

🤔 一句话解释

就像蓝牙耳机自动连接手机一样，DistriBox 让你的 AI 应用自动使用局域网里所有设备的 GPU 算力 — 无需任何配置。

🚀 30 秒开始

# Windows PC
.\distribox.exe
# → 打开 http://localhost:13801

# Android Phone
# → 安装 APK → 点 START WORKER
# → 手机自动通过 mDNS 发现电脑

✨ 核心能力

🔌 系统级虚拟 GPU

通过 OpenCL ICD 技术注册为系统级虚拟设备。任何 OpenCL 应用无需修改即可使用。

📡 零配置局域网

mDNS 自动发现 + 加密 Cluster Token。同一 WiFi 下的设备自动互相发现并安全连接。

🧠 AI 内核引擎

14 个 GPU/CPU 双路径 AI 内核：matmul, gelu, rms_norm, softmax, rope 及更多。

📊 实时仪表盘

Web 仪表盘监控集群状态：虚拟 GPU 规格、Worker 列表、任务吞吐、实时图表。

🔒 安全传输

128-bit Cluster Token + mTLS 双向认证。所有通信加密，仅局域网可访问。

📱 Android 原生

Go ARM64 原生编译的 Android App。支持 Mali/Adreno GPU + CPU 混合计算。
